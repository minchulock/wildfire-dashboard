# 산불 데이터 표준 EDA 절차

아래 순서를 그대로 따른다. 각 단계 결과는 표로 요약해 보여준다.

## 0. 데이터 준비 확인
- `data/raw/fire_stats_*.csv`가 없으면 API를 직접 호출하지 말고, 사용자에게
  `.env` 설정 후 `python -m src.fetch_api --start-year ... --end-year ...` 실행을 안내한다.

## 1. 데이터 개요
- `src/load.py`의 로더로 데이터를 읽는다 (없으면 먼저 작성 제안).
- 행/열 수, 컬럼명·dtype, 기간(최소~최대 연도)을 출력한다.
- 컬럼별 결측치 개수와 비율을 출력한다.

## 2. 품질 점검
- 시도명 고유값 목록을 출력하여 표기 불일치(예: `강원`/`강원도`/`강원특별자치도`)를 찾는다.
- 피해면적 음수·0·극단값(상위 0.1%)을 확인한다.
- 월 값이 1~12 범위인지 확인한다.

## 3. 핵심 집계 (src/analysis.py 함수로 구현)
| 함수 | 내용 |
|---|---|
| `yearly_counts(df)` | 연도별 발생 건수, 피해면적 합계 |
| `region_counts(df)` | 시도별 발생 건수 (내림차순) |
| `monthly_pattern(df)` | 월별 평균 발생 건수 (연도 평균) |
| `cause_share(df)` | 원인별 비중(%) — 선택 |

## 4. 결과 보고
- 각 집계 상위 5개를 표로 보여준다.
- 발견한 패턴을 **3줄 이내 불릿**으로 요약한다. (예: "3~4월에 전체의 약 N% 집중")
- 숫자는 실제 계산 결과만 사용하고, 추정치를 만들어내지 않는다.

## 5. 마무리
- 새로 만든 집계 함수마다 `tests/test_analysis.py`에 최소 1개 테스트를 추가한다.
- 더 깊은 해석이 필요하면 `data-analyst` 서브에이전트에게 위임하라고 제안한다.
